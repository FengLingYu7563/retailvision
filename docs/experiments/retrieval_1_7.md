# 實驗紀錄：驗收 1.7 以圖搜圖（標準圖 gallery）

驗收值的定義：gallery 為 Grocery Store 每個細類 1 張官方白底標準圖、1 個向量；
查詢為 test 集 2,485 張店內實拍；門檻 top-1 >= 70%。

## 最終結果（2026-10-15）

| 模型 | test top-1 | test top-5 | 狀態 |
|---|---|---|---|
| v1：MobileNetV3，只有分類損失 | 52.8% | 83.2% | 未達標 |
| **v2：DINOv2-small + SupCon** | **95.3%** | **99.9%** | **通過**（上線模型） |

## 第一輪（v1，2026-10-14）：不重新訓練，只改 gallery

模型：cls-mnv3-v1（neck 1280 維 embedding）。全部只在 val 296 張上比較。

| # | 做法 | val top-1 | val top-5 |
|---|---|---|---|
| 1 | 標準圖 + 水平翻轉 | 53.0% | 87.5% |
| 2 | 再加 2x2、3x3 排列（模擬一整堆） | 55.4% | 91.2% |
| 2b | 再加中央放大裁切 | 56.1% | 89.5% |
| 3 | 改用 backbone 960 維 pooled 特徵 | 42.9% | 79.4% |
| 4 | 白底摳圖後貼到模糊賣場背景 / 深色背景 | 51.4% 到 52.7% | 86.5% 到 87.2% |

#4 沒有比 #2 進步，觸發「沒有進步」的停止條件。test 結果：嚴格定義 52.8%，#2 增強版 54.5%。

原因：標準圖是單一商品、白底、棚拍光線；測試圖是店內實拍，一整堆商品、裝在塑膠袋裡。
v1 的 embedding 只用分類損失訓練，從來沒看過白底圖，也沒有任何訓練目標要求同類別的兩種照片在 embedding 空間裡靠近。

使用者決定不接受 v1 進入 Phase 2，要求 A、B 兩種重訓方案都試過後比較。

## 第二輪：A 與 B 比較（只看 val）

兩種方案用同一套訓練流程（`training/train_metric.py`）：

- 訓練資料加入標準圖，並做強擴增（換成模糊的賣場背景、排成 2x2 / 3x3、裁切、色彩抖動）。
- PK 取樣：每個 batch 12 個類別 x（1 張標準圖 + 3 張實拍），讓 SupCon 在同一個 batch 裡有同類別的跨 domain 正樣本。
- 損失 = 細類 CE + 0.5 粗類 CE + SupCon（temperature 0.1）。
- 以 val 的「分類 top-1 + 檢索 top-1」選 checkpoint。

為了確認是不是在背答案，兩種方案都先跑「保留類別」版本：固定 seed（1234）挑 20 個細類，實拍和標準圖都不參與訓練。

| 方案 | val 分類 top-1 | val 檢索 top-1（看過的類別） | val 檢索 top-1（沒看過的 20 類，44 張） |
|---|---|---|---|
| 對照：凍結 DINOv2-small，不訓練（CLS token） | 無 | 51.4%（全部類別） | 51.1% |
| A：MobileNetV3 + SupCon | 87.5% | 84.1% | 約 30% |
| **B：DINOv2-small + SupCon** | **96.6%** | **95.7%** | **約 56%** |

觀察：

- A 對看過的類別進步很多，但對沒看過的類別反而比完全不訓練的 DINOv2 還差，表示 A 的進步大部分來自記住這些類別。
- B 在三項都勝出，沒看過的類別也比凍結的 DINOv2 好，表示 SupCon 微調有學到可以遷移的「棚拍對實拍」對應關係。
- 延遲：B 的 ONNX CPU p95 約 56 ms（A / v1 約 7 ms），仍遠低於 API 單張 300 ms 的門檻（驗收 2.12）。

**選擇 B**，用全部 81 類重新訓練成正式模型 cls-dinov2-v2。

## 第三輪：test 正式評估（只跑一次）

| 項目 | test 結果 |
|---|---|
| 1.7 嚴格定義檢索 top-1 / top-5 | **95.3% / 99.9%** |
| 1.4 細類 top-1 / top-5 / 粗類 top-1 | 95.1% / 99.8% / 96.7% |
| 1.6 ONNX 一致性 | 通過 |
| 保留類別實驗：沒看過的 20 類 top-1 / top-5 | 48.5% / 92.9%（662 張） |
| 保留類別實驗：看過的 61 類 top-1 | 95.3%（1,823 張） |

## 如何解讀 95.3%

- 這 81 張標準圖在訓練時被模型看過（經過擴增），查詢用的 test 實拍照則沒有看過。
  所以 95.3% 代表「已登錄商品的標準圖對實拍」的準確率，不代表任何新商品都有這個水準。
- 對完全沒看過的新商品，第一名的準確率約 48.5%，前 5 名約 92.9%。
  新品登錄（Phase 2 的 `/catalog/products`、`/search/similar`）應該回傳前 k 名讓人確認，
  並建議同時上傳店內實拍參考圖。

## 可能的改進方向

- 新商品泛化：更大的 backbone（DINOv2-base）、更多種類的訓練商品、對標準圖做更擬真的合成。
- 延遲：DINOv2 可以做 INT8 量化，或對 CPU 執行緒做調整。
